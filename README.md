
# Player Statistics

This C program reads player names, jersey numbers, and ratings from `players.txt`. It displays each player, counts the players, and calculates their average rating. If the file is empty, it displays “No players found.”

Each line of `players.txt` contains a single-word name, a jersey number, and a rating:

```text
Messi 10 9.5
```

To compile and run the program in the VS Code PowerShell terminal:

```powershell
gcc file3.c -o file3
.\file3
```
